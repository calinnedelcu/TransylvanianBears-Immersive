# Source asset request

The experience must remain truthful to the shipped projects. Generated media may establish atmosphere, but product evidence and gameplay are always sourced from real captures or builds.

## Delivery rules

- Keep original files. Do not resize screenshots before delivery.
- Prefer landscape `1920x1080`, 30 or 60 fps, without browser chrome, notifications, or cursor trails.
- Short raw clips are better than edited reels. The website will handle timing, grading, cropping, and loops.
- Do not add text in the video. Labels remain semantic HTML in the website.
- A ZIP per project is enough; filenames below are recommendations, not blockers.

## Aegis

Priority:

1. `aegis-student-qr-flow.mp4` - 8-15 seconds from opening the student QR to successful validation.
2. Original screenshots for the student, gate, audit, and administrator surfaces.
3. A clean logo or icon asset, preferably SVG or transparent PNG.
4. Optional phone recording showing the real interaction at a school entrance.

The 3D sequence will supply the student, phone, scanner, and turnstile. Real product captures will appear on the phone and gate terminal.

## SchoolMate

Priority:

1. One short screen recording for each confirmed role: student, teacher, parent, secretariat, and gate.
2. Screenshots for announcements, requests/approvals, timetable, and role administration.
3. Any existing diagram that explains the role or Firebase data flow.

The sequence will continue from the Aegis turnstile into a corridor, classroom, and secretariat. Each role will activate a different route through the same school model.

## The Buried Hands

Priority:

1. `buried-hands-guards.mp4` - a clean guard/sound encounter.
2. `buried-hands-mercury.mp4` - the mercury or mask mechanic.
3. `buried-hands-royal-hall.mp4` - the central mechanism or room reveal.
4. A build or repository containing the original Godot project, if it can be shared.
5. High-resolution stills or concept art for the three spaces.

The main story will recreate the lamp, sound, mercury, and pulley interactions in Three.js. Real clips will run as spatial video textures inside the rooms. A web-exportable Godot build can additionally become an optional playable deep dive, but it will not block the main narrative.

## Infect.exe

Priority:

1. The complete level/map as one lossless PNG at native resolution.
2. Player, virus, enemies, effects, and UI as separate sprite sheets with transparency.
3. A 15-30 second unedited gameplay capture.
4. The exact 1-bit palette and the font used by the game.
5. A build or repository, if it can be shared.

With the full map and sprites, the website can perform a real camera traversal while the virus moves through the level. With video alone, it can still build a cinematic CRT sequence, but it will have less interactive depth.

## Temporary production strategy

Until these files arrive, every scene uses an explicit replaceable media socket. Geometry, camera choreography, interactions, responsive framing, and fallbacks can therefore be completed without fabricating project evidence.
